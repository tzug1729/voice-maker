# 声をつくる（VOICEVOXローカル読み上げ）

Windows上のブラウザーで文章を読み上げ、音声を再生・WAV保存するアプリです。Node.jsの小さなローカルサーバーが、同じPCで起動しているVOICEVOXデスクトップアプリへ接続します。サーバーは `127.0.0.1` だけで待ち受けます。文章や音声、プリセットをインターネット上のサーバーへ送信しません。

VOICEVOX本体や音声ライブラリは同梱していません。VOICEVOXとNode.jsを公式配布元から個別にインストールしてください。音声を公開・配布する場合は、使う音声ライブラリの利用規約とクレジット表記を確認してください。

## 必要なもの

- Windows 10/11
- Node.js 20以降（npmを含む）
- VOICEVOXデスクトップアプリ

## インストールと起動

1. [VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/)からVOICEVOXデスクトップアプリをダウンロードしてインストールします。アプリを一度起動し、音声ライブラリのダウンロードなど初期設定を済ませてください。
2. [Node.js公式ダウンロードページ](https://nodejs.org/ja/download)からLTS版をインストールします。インストーラーではnpmも一緒に導入されます。
3. GitHubのリポジトリページで **Code → Download ZIP** を選ぶか、Gitがある場合は次のコマンドで取得します。

   ```powershell
   git clone https://github.com/tzug1729/voice-maker.git
   cd voice-maker
   ```

   ZIPを使う場合は展開して、展開した `voice-maker` フォルダーを開いてください。
4. `起動.cmd` をダブルクリックします。初回は必要なNode.jsパッケージを準備したあと、ブラウザーで `http://127.0.0.1:3000` を開きます。
5. VOICEVOXデスクトップアプリを起動した状態で、画面からプリセットを選び、文章を入力して **音声をつくる** を押します。できあがった音声はページ上で再生でき、**WAVを保存** から保存できます。

`起動.cmd` が使えない場合は、VOICEVOXを起動し、プロジェクトフォルダーでPowerShellを開いて次を実行してください。

```powershell
npm ci
npm start
```

その後、ブラウザーで `http://127.0.0.1:3000` を開きます。

## プリセット

起動時に `presets.default.json`（配布用）と `%LOCALAPPDATA%\voice-maker\presets.json`（このPCで保存したもの）を読み込みます。配布用JSONのプリセットと、この画面から保存した個人用プリセットを選択欄に表示します。以前のユーザー用JSONに残っている別話者のプリセットは表示しません。プリセットはVOICEVOXの既存話者・スタイルIDと合成値の組み合わせです。新しい音声モデルは作りません。

配布するプリセットを追加・変更するには、プロジェクト直下の `presets.default.json` を編集してGitHubに反映します。話者・スタイルは `styleId` にVOICEVOXエンジンのスタイルIDを設定します。VOICEVOXを起動し、`http://127.0.0.1:50021/speakers` を開くと話者名と `styles` 内の `id` を確認できます。`speedScale`、`pitchScale`、`intonationScale`、`volumeScale`、`prePhonemeLength`、`postPhonemeLength` は必要な数値を指定します。未設定の話者IDや数値のプリセットは選択欄に出しません。

たとえば、ヒナをずんだもんの声にする場合は、ヒナの項目の `styleId` をVOICEVOXの「ずんだもん／ノーマル」に対応するIDに設定します。ずんだもんやもち子さんを別々に選びたい場合は、JSONにそれぞれ別のプリセット項目を追加します。利用規約とクレジット表記も確認してください。

## 読み上げごとにパラメータを調整

読み上げ画面でプリセットを選ぶと、VOICEVOXにインストールされた話者・スタイルの選択欄と、話速・高さ・抑揚・音量・前後の無音時間のスライダーが表示されます。話者や値を変更してから音声を生成できます。**保存値に戻す** で選択したプリセットの話者と数値に戻せます。話者一覧が表示されない場合は、VOICEVOXを起動してページを再読み込みしてください。

調整後の話者と値を別名で残すには、**現在の設定を新しいプリセットとして保存** を押して名前を入力します。個人用JSONに追加され、次回起動時も読み込まれます。配布用JSONは変更しません。

## 終了方法

起動時に開いた黒いウィンドウで `Ctrl+C` を押し、終了確認が出たら `Y` を押すか、ウィンドウを閉じます。VOICEVOXデスクトップアプリも不要になったら通常の方法で終了してください。

## VOICEVOXが起動していないとき

「VOICEVOXに接続できません」と表示されたら、VOICEVOXデスクトップアプリを起動して読み込みが終わるまで待ち、もう一度操作してください。VOICEVOXの標準エンジンURL `http://127.0.0.1:50021` を使用します。

## 開発者向け

- `npm start` — ローカルAPIと静的画面を起動
- `npm test` — Node.js標準テストを実行（音声生成部分はVOICEVOXのHTTP応答を模擬）

プリセットは `%LOCALAPPDATA%\voice-maker\presets.json` に保存します。`DATA_DIR` と `ENGINE_URL` 環境変数は任意の開発・検証用設定です。通常の利用では設定不要です。
